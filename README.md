# 📝 Notes Saving Web Application

🚀 A full-stack Notes Saving Website built using *Python (Flask)* and *MongoDB Atlas*.
This application allows users to securely register, login, and manage their personal notes online.

## ✨ Features

* 🔐 User Authentication (Register & Login)
* 📝 Add Notes
* 📖 View Notes
* ❌ Delete Notes
* 👤 User-specific Notes (each user sees only their data)

## 🛠️ Tech Stack

* 🐍 Python
* ⚡ Flask
* 🍃 MongoDB Atlas
* 🌐 HTML, CSS
* 🔧 Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository


git clone https://github.com/yourusername/notes-app.git
cd notes-app


### 2️⃣ Install Dependencies


pip install flask pymongo werkzeug


### 3️⃣ Configure Database

* Create a MongoDB Atlas cluster
* Replace connection string in app.py

### 4️⃣ Run Application


python app.py


### 5️⃣ Open in Browser


http://127.0.0.1:5000

## 🌍 Database

This project uses *MongoDB Atlas (Cloud Database)* for storing user data and notes.

## 🔐 Security

* Passwords are stored using *hashing*
* Session-based authentication is used
